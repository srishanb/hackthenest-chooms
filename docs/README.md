# Docs index

What is in `docs/`. Rules for every agent are in [AGENTS.md](../AGENTS.md). The project pitch is in the root
[README.md](../README.md).

| Document | What it is | For |
|---|---|---|
| [PLAN.md](PLAN.md) | Master plan: architecture, phases, schedule, and the "stays off" list. | Everyone building |
| [STATUS.md](STATUS.md) | Status of each feature (Proposed, In progress, Built, Done, Cut). Integrator edits it. | Everyone, judges |
| [FEATURES.md](FEATURES.md) | The final feature list. | Everyone, judges |
| [DECISIONS.md](DECISIONS.md) | One line per decision (D-numbers). Integrator edits it. | Everyone building |
| [QUEUE.md](QUEUE.md) | Ordered task list for the continuous builder. Integrator edits it. | Agents, integrator |
| [HUMAN_TASKS.md](HUMAN_TASKS.md) | Things only a person can do (hardware, accounts, recordings). | Team |
| [OCTOPUS_TEST.md](OCTOPUS_TEST.md) | First-run steps for the PiEEG Octopus 16 on a head. Written for a person with the board; not run on real hardware by the builder. | Whoever has the board |
| [STAGE_EDITOR.md](STAGE_EDITOR.md) | How the Stage Editor publishes a layout as a pull request. | Level and stage editors |
| [visual-design.md](visual-design.md) | Notes on the forest visuals and the public preview checkbox. | UI, content |
| [forest-source-inventory.json](forest-source-inventory.json) | Machine-readable list of forest art packs used. | Content, credits |
| [DEMO.md](DEMO.md) | Demo script. Added by an open pull request; may not be on `main` yet. | Presenters |
| [DEVPOST.md](DEVPOST.md) | Devpost submission copy. Added by an open pull request; may not be on `main` yet. | Submitters |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Architecture overview. Added by an open pull request; may not be on `main` yet. | Judges, new builders |
| [onboarding/](onboarding/README.md) | Team onboarding page plus one file per person (`ali.md`, `amrit.md`, `neil.md`). | New team members |
| [plans/](plans/README.md) | One plan file per phase or change (`P0.md` to `P12.md` and named plans). Index in `plans/README.md`. | Lane owners, reviewer |
| [agent-reports/](agent-reports/TEMPLATE.md) | One after-job report per agent task, named `<date-time>-<agent>-<task>.md`. Template in `TEMPLATE.md`. | Reviewer, integrator |
| [screenshots/](screenshots/) | Reference screenshots grouped by topic (atmosphere, corruption, forest, polish, tuning). | Content, UI |
| [licenses/](licenses/) | License texts for bundled third-party art (`bkt-glitch`, `cold-corridors`). | Credits |

The signal is composure (calm versus tension). Nothing here claims a medical or therapeutic effect, and nothing
has been verified on a real PiEEG Octopus 16 board.
