## 7. Can a teammate explain this?

While the game is paused, Recalibrate opens instructions for two signal baselines. Each step changes its instruction halfway and waits for the signal system's real result. A failed step offers retry or an honest steady-light/rescue fallback, and closing the dialog leaves the game paused.
