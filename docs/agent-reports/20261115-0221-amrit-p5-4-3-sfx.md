## 3. Problems, workarounds and dead ends

- Engine tests now explicitly request empty SFX assets, so they remain isolated from real file loads while SFX has independent tests.

## 7. Can a teammate explain this?

Game events choose one local sound file; the UI does not control gameplay to make it happen. The existing audio bus applies player volumes, and paused games stop or ignore cues. Missing files use a brief tone, and voice limits and cleanup keep events from accumulating audio sources.
