## 7. Can a teammate explain this?

`recorder.ts` records band-power frames, composure states, and game events as JSONL lines without storing raw EEG samples or names. `tools/eval/run-eval.ts` replays any JSONL recording headlessly through a chosen algorithm so we can compare algorithms offline on `recordings/sim-fixture.jsonl`. The debug overlay now shows all signal diagnostics with aligned columns, lets developers run active/resting calibration, shows simulator keybindings when using the simulator, and downloads recorded JSONL logs.
