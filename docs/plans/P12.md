## Goal

A brief, opt-in, adjustable camera shake on hard landings, scaled by fall height; never under reduced motion.

## What exists already

`Settings.landingShake: boolean` (default `false`) and `reducedMotion` exist. P4.3 plans `land { fallHeightPx }`.
`Camera.shake(duration, intensity)` is verified in `phaser.d.ts` (line 4014) and `skills/cameras` (intensity is a
fraction of the view, default 0.05). No shake code exists. P2's settings panel plan does not list a shake control.

## Contract changes requested (optional)

1. `settings.ts`: `Settings` gains `landingShakeStrength: number` (0..1, default 0.5), so the shake is adjustable.
2. `config.ts`: `GameConfig` gains `landingShake: { minFallPx: number; maxDurationMs: number; maxIntensity: number }`.
3. **Fallback if declined:** on/off only, scaled by fall height; the threshold reuses `EmberConfig.minFallPxToOffer`,
   and the two maxima are named constants in the file header.

## Files (game lane)

`src/game/effects/landing-shake.ts` (only pure `shakeFor`; the `cameras.main.shake` call stays in the scene,

## Tasks and acceptance tests

### P12.1 Landing shake (one task, about 1 hour)

1. Pure `shakeFor(fallHeightPx: number, settings: Settings, cfg: LandingShakeConfig): { durationMs: number;
   intensity: number } | null`. Null if `landingShake` is false, `reducedMotion` is true, or the fall is below
   `minFallPx`. Otherwise both values grow with fall height up to their maxima, times the strength.
2. The scene listens to its own `land` event and calls `cameras.main.shake(durationMs, intensity)`. Never while the
   phase is `'ember'` or `'paused'`. It reads no `ComposureState` and no `EffectsFrame`. This is not the cut
   "continuous camera instability": one brief, opt-in shake per hard landing, caused by the fall only.

| Acceptance test | How |
|---|---|
| Off by default, off under reduced motion | Unit: defaults → null; `landingShake` and `reducedMotion` both on → null. |
| Scaled and capped | Unit: below `minFallPx` → null; a bigger fall → longer, stronger, never above the maxima. |
| Independent of EEG | `rg -n -e composure -e EffectsFrame src/game/effects/landing-shake.ts` prints nothing. |
| Feels right | Browser: turn it on, drop from a high ledge: one short shake; turn reduced motion on: none. |
