## Tasks, in order

1. `npm init`, add the pinned dependencies, commit the lockfile.
2. `tsconfig.json`, `vite.config.ts`, `index.html`; confirm `npm run dev` serves on the worktree's `PORT`.
3. **Spike (20 minutes, time-boxed):** Arcade body lands on a static platform; a darkness layer with a light hole
   renders above the world and below a marker sprite. If either cannot be made to work in Phaser 4.2.1 inside the
   box, switch `phaser` to `3.90.0`, note it in `DECISIONS.md`, and continue.
4. `src/shared/` contracts, bus, store, tests.
5. `src/config/` value files.
6. Lane stubs and `src/main.ts`.
7. Lane-boundary test.
8. Vendor `pieeg.js`; do not wire it into the signal lane (that is P1.1).
9. `ci.yml`; update `ai-review.yml` so it does not merge while CI is failing.
10. Update `README.md` "verify your setup" if any command differs from the plan.
11. After-job report; PR labelled `no-automerge`.

## Acceptance tests

| # | Test | How |
|---|---|---|
| 1 | Clean install and checks pass | `npm ci && npm run check` exits 0 on the Mac (agent) and on at least one Windows laptop (human, Git Bash). |
| 2 | Dev server uses the worktree port | `npm run dev` prints `localhost:<PORT from .env.local>`. |
| 3 | Canvas and physics | In Chrome, the box lands on the platform and moves with Left and Right. |
| 4 | Signal reaches the screen through the contracts | The light radius visibly breathes with the stub sine; the debug overlay (backtick) shows `intensity` changing; the badge reads `SIMULATED INPUT`. |
| 5 | UI is removable | Set every component to `enabled: false` in `ui.config.ts`; the box still moves and nothing throws. |
| 6 | Lane boundaries are enforced | Add a temporary `import` from `src/signal` into `src/game`; `npm test` fails; remove it. |
| 7 | Offline | `npm run build && npm run preview`, turn Wi-Fi off, hard-reload: the page works and the network tab shows no failed requests. |
| 8 | No secrets and no CDN | `rg -n "https?://" index.html src public --glob '!public/vendor/**'` shows no runtime URL; `.env.example` has names only. |

## Risks

| Risk | Response |
|---|---|
| TypeScript 7 or Vitest 5 fails against Phaser's types | Pin the newest TypeScript 6.x; record it in `DECISIONS.md`. |
| The Phaser 4 darkness spike overruns its 20 minutes | Fall back to phaser 3.90.0 (task 3). |
| `npm` cache permission error on Srishan's Mac (`~/.npm` has root-owned files) | Run `sudo chown -R 501:20 ~/.npm` once (a human runs it), or use `npm_config_cache=$TMPDIR/npm-cache`. |
| Contracts turn out wrong during P1 or P4 | Expected once or twice. A small integrator PR; announce it to the team. |

## Out of scope

Any real signal processing, movement tuning, levels, UI content, audio or narrator. Wiring `pieeg.js`.
