## Goal

Two music layers (quiet and tense) loop together and crossfade from `EffectsFrame.musicTenseMix`. Four volumes from
`Settings` apply live. Music gain is capped so jump and landing sounds are never masked, refuges are quieter, and
the ember activation plays simplified audio. Everything works with no audio files at all.

### Recommendation: Web Audio API directly, not Phaser's sound manager

| | Web Audio API in `src/audio/` | Phaser sound manager (`this.sound`) |
|---|---|---|
| Reachable from the audio lane | Yes, it is a browser API | No: it lives on the game instance in Ali's lane |
| Gesture unlock | We call `resume()` on the first key or click | Automatic (Phaser skill, "unlocked" event) |
| Crossfade and caps | Gain nodes per bus, smooth ramps | Per-sound `volume`, set by hand each frame |
| Contract change | None | The game would have to expose `sound` (a contract) |

Use the Web Audio API. The names `AudioContext`, `GainNode`, `AudioParam.setTargetAtTime`,
`AudioBufferSourceNode` (`loop`), `decodeAudioData`, `OscillatorNode` and `AudioContext.resume()` are
**unverified in this plan: check each on MDN before use.** Optional request to Ali: set Phaser's
`audio: { noAudio: true }` (verified in `phaser/skills/audio-and-sound/SKILL.md`) so two audio contexts never compete.

**Gesture rule.** Browsers start an `AudioContext` suspended until a user gesture (unverified detail: check MDN
"Autoplay guide"). `createAudio` creates the context at once, and adds one-time `keydown` and `pointerdown`
listeners on `window` that call `resume()`. Until then nothing is audible and nothing errors. The first key a
player presses (menu or Space) unlocks it.

## Tasks and acceptance tests

### P5.4.1 Mix rules (pure, no browser)

1. `computeMix(input: MixInput, config: AudioConfig): MixGains` where `MixInput` holds `tenseMix01`, `volumes`,
   `phase`, `inRefuge` and `emberActive`, and `MixGains` is `{ quiet, tense, sfx, narrator }`, all 0..1.
2. Rules: music gain = `master × music × maxMusicGain × scale`, where `scale` is 1 when playing, `refugeMusicScale`
   in a refuge, `emberMusicScale` during the ember, and `pausedMusicScale` when paused. The quiet layer gets
   `1 − tenseMix` of it and the tense layer gets `tenseMix`, using an equal-power curve (`cos` and `sin`).
   During the ember the tense layer is 0 (simplified audio). SFX gain = `master × sfx`. Narrator = `master × narrator`.
3. Clamp every input to 0..1 and treat `NaN` as the neutral value, so a bad frame never makes a loud sound.

| Acceptance test | How |
|---|---|
| Music never exceeds the cap | Unit test over a grid of inputs: `quiet² + tense² ≤ (master·music·maxMusicGain)²`. |
| SFX stay louder than music | At full tense mix and default volumes, `sfx ≥ 1.4 × max(quiet, tense)`. |
| Refuge and ember are quieter | Same input: refuge and ember totals are below the playing total; ember `tense = 0`. |
| Volumes at 0 silence a bus | `music = 0` makes both layers 0; `master = 0` makes all four 0. |
| Bad input is safe | `tenseMix01 = NaN` or `2` gives the same gains as 0.3 or 1. |

### P5.4.2 Engine and music layers

1. `engine.ts`: one `AudioContext`, a master gain, and three bus gains (music, sfx, narrator). The gesture unlock
   above. Every gain change uses a smooth ramp with time constant `musicCrossfadeMs / 3` (never a jump).
2. `loader.ts`: fetch each local file from `asset-list.ts` and decode it. A missing file or a decode error logs one
   warning and returns `null`. Never throws, never retries, never touches another host.
3. `music-layers.ts`: start the quiet and tense buffers looping in sync at the same moment; a `null` layer is silent.
4. `index.ts`: `createAudio` subscribes to `stores.effects`, `stores.snapshot` and `stores.settings` and applies
   `computeMix` at most about 10 times a second, and only when a gain changed by more than 0.01.

| Acceptance test | How |
|---|---|
| No files, no errors | `npm run dev`, no audio files: one warning per file, no uncaught errors (404 lines are fine). |
| Gesture unlock | Browser: load, press any key, then jump: a sound (or the placeholder tone) plays. |
| Crossfade follows the signal | Neil's files, `musicTenseMix` on, both overlay Calibrate buttons passed, then press |
| | `Digit2` repeatedly: the tense layer rises within about 10 s (two smoothers: 3 s and 4 s). |
| Volumes apply live | Settings panel (P2.2) or `stores.settings` in DevTools: music 0 silences music at once. |
| Lane rule | `npm run check` passes, including the lane-boundary test. |

### P5.4.3 SFX, refuges and the ember

1. `sfx-map.ts` (pure): `jump` → `jump`; `land` → `land` (or `landHard` when `fallHeightPx ≥ bigFallPx`, read from
   `EMBER_CONFIG`); `refuge_enter` → `refuge`; `checkpoint_saved` → `save`; `ember_gained`, `ember_requested`,
   `ember_returned`, `ember_cancelled` → their own ids; `finish` → `finish`. Unknown events map to nothing.
2. `sfx.ts`: plays a decoded buffer on the SFX bus. If the file is missing it plays a 100 ms quiet tone, so jump and
   landing are audible before Neil's files arrive. No sound while `phase` is `paused`.
3. Apply the refuge rule (contract field or the fallback above) and the ember rule from P5.4.1.

| Acceptance test | How |
|---|---|
| Event mapping | Unit test: each listed event gives its id; a big landing gives `landHard`; `pause` none. |
| Jump and land audible at full mix | After calibrating, press `Digit2` repeatedly until the mix is high; jump |
| | and land: both are clearly heard. |
| Refuge is quieter | Browser: walk into the refuge: the music drops within about 2 s and returns after leaving. |
| Ember is simplified | Browser: start an ember (P6.3): the tense layer fades out; it returns after `ember_returned`. |
